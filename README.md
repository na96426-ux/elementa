# Elementa

불, 물, 흙, 공기 네 가지 원소에서 시작해 88개의 원소를 조합으로 발견하는 브라우저 게임입니다.

## 실행

`index.html` 파일 하나로 동작합니다. 브라우저로 열면 바로 플레이할 수 있고, 설치나 빌드가 필요 없습니다.

## 플레이 방법

- 선반의 원소를 두 번 차례로 누르면 작업대에서 섞입니다. 같은 원소를 두 번 눌러도 됩니다.
- 새 원소를 발견하면 설명 카드가 뜨고, 분류(원소, 대지, 하늘, 생명, 인간, 문명, 기술)가 하나씩 열립니다.
- 하나의 원소를 만드는 방법이 여러 개인 경우가 많습니다. 이미 아는 원소를 다른 방법으로 만들면 "새로운 조합"으로 알려줍니다.
- 더 만들 것이 없는 원소는 흐리게 표시되고, "다 쓴 원소 숨기기"로 감출 수 있습니다.
- "발견 카드 보기"를 끄면 새 분류가 열리거나 게임을 끝낼 때만 카드가 뜹니다.
- 힌트를 한 번 누르면 재료 하나를, 한 번 더 누르면 짝까지 알려줍니다. 새 정보를 줄 때만 힌트 횟수가 올라갑니다.
- 원소를 고를 때, 새 원소를 발견할 때, 조합에 실패할 때마다 효과음이 납니다. 오른쪽 위 버튼으로 소리를 끌 수 있습니다.
- 키보드만으로도 플레이할 수 있습니다. Tab으로 이동하고 Enter나 Space로 누르며, Esc로 카드를 닫습니다.
- 진행 상황은 브라우저에 자동 저장됩니다.

## 원소와 레시피 추가

`index.html` 안의 `ELEMENT_DATA`에 `이름|이모지|분류|설명` 줄을, `RECIPE_DATA`에 `재료1+재료2=결과` 줄을 추가하면 됩니다. 같은 결과를 내는 레시피를 여러 줄 넣으면 모두 정답으로 인정됩니다.

# Elementa

불, 물, 흙, 공기 네 가지 원소에서 시작해 **206개의 원소**를 조합으로 발견하는 브라우저 게임입니다.

## 실행

`index.html` 파일 하나로 동작합니다. 브라우저로 열면 바로 플레이할 수 있고, 설치나 빌드가 필요 없습니다.

## 플레이 방법

- 선반의 원소를 두 번 차례로 누르면 작업대에서 섞입니다. 같은 원소를 두 번 눌러도 됩니다.
- 새 원소를 발견하면 설명 카드가 뜨고, 분류(원소, 대지, 하늘, 생명, 인간, 음식, 문명, 기술, 전설)가 하나씩 열립니다.
- 하나의 원소를 만드는 방법이 여러 개입니다(레시피 582개). 이미 아는 원소를 다른 방법으로 만들면 "새로운 조합"으로 알려줍니다.
- **업적** 24개가 있습니다. 발견 개수, 분류 완성, 새로운 조합, 힌트 없이 발견, 연속 발견, 특정 원소(인간·김치·용·우주인·인공지능 등) 발견 등으로 열립니다. 오른쪽 업적 패널에서 배지를 누르면 조건이 보입니다.
- **원소 찾기** 칸에 이름을 치면 선반에서 바로 걸러집니다. Esc로 지웁니다.
- 더 만들 것이 없는 원소는 흐리게 표시되고, "다 쓴 원소 숨기기"로 감출 수 있습니다.
- "발견 카드 보기"를 끄면 새 분류가 열리거나 게임을 끝낼 때만 카드가 뜹니다.
- 힌트를 한 번 누르면 재료 하나를, 한 번 더 누르면 짝까지 알려줍니다. 새 정보를 줄 때만 힌트 횟수가 올라갑니다.
- 원소를 고를 때, 새 원소를 발견할 때, 조합에 실패할 때, 업적을 달성할 때 효과음이 납니다. 오른쪽 위 버튼으로 소리를 끌 수 있습니다.
- 키보드만으로도 플레이할 수 있습니다. Tab으로 이동하고 Enter나 Space로 누르며, Esc로 카드를 닫습니다.
- 진행 상황(발견한 원소, 조합, 업적, 통계)은 브라우저에 자동 저장됩니다.

## 원소와 레시피 추가

`index.html` 안의 `ELEMENT_DATA`에 `이름|이모지|분류|설명` 줄을, `RECIPE_DATA`에 `재료1+재료2=결과` 줄을 추가하면 됩니다. 같은 결과를 내는 레시피를 여러 줄 넣으면 모두 정답으로 인정됩니다. 분류 키는 `base, earth, sky, life, human, food, civ, tech, myth` 입니다.

업적은 `ACH` 배열에 `{ id, emoji, name, desc, test }`를 추가합니다. `test()`는 현재 상태를 보고 참/거짓만 돌려주면 됩니다.

## 검수 도구 (`_작업/`)

- `sim.py` — `index.html`의 데이터를 읽어 도달 가능성·충돌·막다른 원소를 검사하고, 무작위 플레이를 수천 판 돌려 어느 원소가 늦게 발견되는지 알려줍니다. `python3 -I _작업/sim.py 2000`
- `serve.py` — 브라우저 자동 검수용 로컬 서버. `python3 -I _작업/serve.py 8765`
- `author.py` + `build.py` — 2026-10 대확장 때 쓴 초안·주입 도구. 지금은 `index.html`이 유일한 원본이므로 참고용입니다.

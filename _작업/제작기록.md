## 어거지 레시피 검수 결과
블라인드 평가자 2명(서브에이전트, 레시피 목록만 보고 1~5점)이 공통으로 2점 준 것은 전부 바꿨다:
`흙+공기=모래`(삭제) · `구름+바람=하늘`(→폭풍) · `구름+구름=하늘`(→비) · `물+바람=얼음`(→ 새 원소 **추위**: 바람+산, 바람+밤 / 얼음=물+추위) · `박테리아+흙/식물=곤충`(→생명+식물·생명+초원) · `도마뱀+공기=새`(→도마뱀+하늘·공룡+공기) · `도마뱀+용암=공룡`(→도마뱀+도마뱀) · `도마뱀+숲=짐승`(→생명+숲) · `짐승+불=인간`(→원숭이+불·원숭이+도구) · `하늘+돌=달`(→밤+돌·우주+돌) · `비행기+하늘=로켓`(삭제) · `전기+집=전구`(→전기+등불) · `전기+책=컴퓨터`(→전기+기계) · `바다+전기=생명`(삭제) · `도구+흙=밀`(→밭).

## 검수 방법과 결과
1. `sim.py`: 충돌 0 · 도달 불가 0 · 무작위 플레이 3,000판×2방식 전부 완주. 늦게 남던 치즈·꿀·오토바이·도서관·벌·알·우유에 대체 레시피를 보강.
2. 브라우저(`serve.py`로 띄움, javascript로 클릭 자동화): 레시피 순서대로 206개 전부 발견(조합 202번, 5.6초, 오류 0) → 남은 레시피 전부 "새로운 조합" 판정 → 실패 60번 → **업적 24/24** 전부 발동 · 새로고침 후 저장 복원 확인 · 무작위 20판.
3. 기능: 검색·Esc·다 쓴 원소 숨기기·탭·힌트 2단계·슬롯 빼기·초기화 확인창·발견 카드 연타 방지.

## 다시 돌리는 법
```
python3 -I _작업/sim.py 2000          # 데이터 검증 + 시뮬레이션
python3 -I _작업/serve.py 8765        # http://127.0.0.1:8765 에서 브라우저 검수
```
데이터를 손볼 때는 `index.html`의 `ELEMENT_DATA`·`RECIPE_DATA`를 직접 고치고 `sim.py`를 돌린다. (`author.py`/`build.py`는 이번 대확장 초안용이라 지금 `index.html`과 다를 수 있다. 다시 쓰려면 먼저 `index.html` 쪽을 author.py에 옮길 것.)
